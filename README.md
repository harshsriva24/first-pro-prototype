# FIRST Pro prototype

Clickable prototype of the FIRST Pro professional-loan journey inside the IDFC FIRST Bank app shell.
Built by Team Challengers (Harsh Srivastava, Shwetambara Sahay, Shivam Jhamb), IMT Ghaziabad, for the IDFC FIRST Bank FAME 6.0 Open Innovation Challenge, Problem Statement 5.

Open `index.html` or the GitHub Pages link. Design mock-up only; no real banking functions.
